# replicated key value


- this project is a simple implementation of a in-memory replicated key value store

- right now it's a two node (primary and replica) without any leader election 

- this project will be extended into adding more nodes and implementing different consesus algorithm

- the initial fault model is crash fault and later expanding to other fault model e.g byzantine fault

- this serves as the primary application we be test on a new dst harness in the making

> [!NOTE] no LLMS or agentic coding is being used to write the code everything is handwritten apart from research
